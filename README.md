
# Static Website Hosting on Amazon S3

## About the Project
This project involves building a personal portfolio website using HTML and CSS and hosting it as a static website on Amazon S3.

The main goal is to gain practical experience with AWS cloud services and understand how static websites can be deployed and made accessible over the internet.

## Technologies Used
- HTML
- CSS
- Amazon S3
- Git
- GitHub

## AWS Learning Objectives
- Understand Amazon S3 buckets and objects.
- Create and configure an S3 bucket for static website hosting.
- Upload website files to Amazon S3.
- Learn about bucket policies and public access settings.
- Deploy and test a live static website.
- Understand basic AWS security and cost considerations.

## Project Features
- Personal portfolio homepage.
- About Me section.
- Skills and projects sections.
- Responsive website design.

## Deployment
The website will be deployed to Amazon S3 as part of this project.
